## 🎮 Sobre o Steam Inject

O **Steam Inject** foi desenvolvido para facilitar o processo de configuração dos jogos adquiridos pela **TM Store Games**.

A ferramenta auxilia na preparação do jogo para utilização através da Steam, seguindo as instruções fornecidas junto ao produto adquirido.

> ⚠️ O Steam Inject é destinado exclusivamente aos jogos adquiridos pela **TM Store Games**.

## 📦 Instalação

1. Acesse a página de **Releases**.
2. Baixe o arquivo `SteamInject.exe`.
3. Execute o aplicativo.
4. Siga as instruções apresentadas pelo Steam Inject.
5. Utilize a ferramenta conforme as instruções fornecidas junto ao jogo.
